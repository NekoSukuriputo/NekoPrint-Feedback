# NekoPrint Feedback

Public feedback and issue tracker for **NekoPrint: Thermal & Label**, an Android app that prints
receipts, marketplace shipping labels, PDFs, Word files, photos and QR/barcode labels to Bluetooth,
USB and Wi-Fi thermal and label printers.

> The app's source code is not in this repository. This repo only collects bug reports, printer
> compatibility reports, feature requests and translation fixes.

## English

### Join the closed test

NekoPrint is in closed testing on Google Play. You do **not** need a thermal printer to help.

1. Join the tester group: <https://groups.google.com/g/nekoprint-testers>
2. Opt in to the test: <https://play.google.com/apps/testing/dev.nekosukuriputo.nekoprint>
   and tap **Become a tester**.
3. Install NekoPrint from Google Play:
   <https://play.google.com/store/apps/details?id=dev.nekosukuriputo.nekoprint>
4. Please keep the app installed for at least **14 days** and open it a few times.

Google Play requires every new app to keep at least 12 testers for 14 days in a row, so staying
opted in for the full period really helps.

### Report something

[Open a new issue](https://github.com/NekoSukuriputo/NekoPrint-Feedback/issues/new/choose) and pick
a template:

| Template | Use it for |
| :--- | :--- |
| 🐞 Bug report | Crashes, wrong output, buttons that do nothing, purchase problems |
| 🖨️ Printer compatibility | "My printer works / does not work" (brand, model, connection) |
| 💡 Feature request | Ideas and improvements |
| 🌐 Translation | Wrong or missing text in one of the 16 languages |

Before you post, please search the [existing issues](https://github.com/NekoSukuriputo/NekoPrint-Feedback/issues)
to avoid duplicates.

#### Helpful details

- **App version:** Settings › About (for example `Version 1.0.0 (7)`).
- **Purchase or "We couldn't verify this purchase" problems:** open Settings › About and **tap the
  version line 7 times**. A short list of diagnostic codes appears (for example
  `PURCHASE_VERIFY/…`, `TAMPER/…`). Add a screenshot of it to your report. The codes contain no
  personal data.
- **Screenshots or a short screen recording** help a lot.

### Privacy

This repository is **public**. Do not post:

- documents, receipts or shipping labels that show names, addresses, phone numbers or order numbers
  (blur them first),
- your email address, purchase receipts or order IDs,
- anything you would not want the whole internet to see.

For private matters (for example a purchase that needs a refund), email
**nekosukuriputo@gmail.com** instead. Privacy policy:
<https://nekosukuriputo.dev/NekoPrint/privacy_policy.html>

## Bahasa Indonesia

### Ikut pengujian tertutup

NekoPrint sedang dalam pengujian tertutup di Google Play. Anda **tidak perlu** punya printer
thermal untuk membantu.

1. Gabung grup penguji: <https://groups.google.com/g/nekoprint-testers>
2. Daftar jadi penguji: <https://play.google.com/apps/testing/dev.nekosukuriputo.nekoprint>
   lalu ketuk **Jadi penguji**.
3. Install NekoPrint dari Google Play:
   <https://play.google.com/store/apps/details?id=dev.nekosukuriputo.nekoprint>
4. Mohon jangan uninstall minimal **14 hari**, dan buka aplikasinya sesekali.

Google Play mewajibkan aplikasi baru punya minimal 12 penguji selama 14 hari berturut-turut, jadi
tetap terdaftar sampai selesai sangat membantu.

### Laporkan sesuatu

[Buat issue baru](https://github.com/NekoSukuriputo/NekoPrint-Feedback/issues/new/choose) lalu pilih
template:

| Template | Untuk |
| :--- | :--- |
| 🐞 Bug report | Aplikasi tertutup sendiri, hasil cetak salah, tombol tidak bekerja, masalah pembelian |
| 🖨️ Printer compatibility | "Printer saya bisa / tidak bisa" (merek, model, koneksi) |
| 💡 Feature request | Ide dan usulan fitur |
| 🌐 Translation | Teks salah atau belum diterjemahkan di salah satu dari 16 bahasa |

Sebelum memposting, cek dulu [issue yang sudah ada](https://github.com/NekoSukuriputo/NekoPrint-Feedback/issues)
supaya tidak dobel.

#### Detail yang membantu

- **Versi aplikasi:** Pengaturan › Tentang (misalnya `Versi 1.0.0 (7)`).
- **Masalah pembelian atau "Kami tidak dapat memverifikasi pembelian ini":** buka Pengaturan ›
  Tentang lalu **ketuk baris versi 7 kali**. Akan muncul daftar kode diagnostik (misalnya
  `PURCHASE_VERIFY/…`, `TAMPER/…`). Lampirkan screenshot-nya. Kode ini tidak berisi data pribadi.
- **Screenshot atau rekaman layar singkat** sangat membantu.

### Privasi

Repository ini **publik**. Jangan memposting:

- dokumen, struk, atau resi yang memuat nama, alamat, nomor telepon, atau nomor pesanan (buramkan
  dulu),
- alamat email, bukti pembelian, atau ID pesanan,
- apa pun yang tidak ingin dilihat semua orang di internet.

Untuk hal pribadi (misalnya pembelian yang perlu pengembalian dana), kirim email ke
**nekosukuriputo@gmail.com**. Kebijakan privasi:
<https://nekosukuriputo.dev/NekoPrint/privacy_policy.html>
